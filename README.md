# Claude Code for iPhone — la web del producto

La web pública de venta y la **guía de instalación** de Claude Móvil: Claude
Code corriendo en un VPS propio y manejado desde el iPhone con una terminal
web persistente.

## Qué hay

- `index.html` — el escaparate: qué es, qué incluye y el precio
  (instalación + suscripción anual).
- `guia-instalacion.html` y `guia-instalacion.pdf` — la guía completa de
  instalación, en web y en PDF descargable.

## Cómo funciona

Estático puro, sin compilación y sin dependencias. Es el repositorio
**público** de la cuenta — los demás son privados — precisamente porque es
el escaparate. El producto que explica vive en el repositorio `claude-movil`.
